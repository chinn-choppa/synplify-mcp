# Совместимость

| Уровень | Ожидается | Подтверждено на момент создания |
| --- | --- | --- |
| Python | 3.11+ | CI: Python 3.11/3.13 на Windows/Linux; Python 3.15.2: интеграционный CI PASS, Windows/Linux (79 тестов в каждой среде) |
| MCP | SDK 2.3.0, stdio | `MCP_TOOL_PASS`: Windows/Linux, Python 3.11/3.13, синтетический `parse_srr` через реальный клиент; см. CI PR #10 |
| Windows | Планируется | EDA `NOT_RUN` |
| Linux | Планируется | EDA `NOT_RUN` |
| Synopsys Synplify Pro | Разные версии, после исследования | `NOT_RUN` |
| Корпоративные проекты | Только в разрешённой среде | Не использовались |

Прототип не устанавливает EDA-бинарник и не проверяет его лицензию. Пользовательские версии инструмента выбираются явно через `SYNPLIFY_MCP_EXECUTABLE` или стандартный `PATH` только для безопасного обнаружения. Экспериментальный запуск требует отдельного включения оператором, манифеста утверждённых `.prj` и доверенного workspace. На лицензионном Synplify запуск по-прежнему `NOT_RUN`; см. [руководство](APPROVED_RUN.md).

Synplify — коммерческий продукт. Этот репозиторий не включает исполняемые файлы, лицензии и проприетарные образцы отчётов.
