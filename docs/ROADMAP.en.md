## Bootstrap

- [x] Standalone local stdio MCP package, read-only diagnostic tools and executable discovery.
- [x] uv setup, security guidance and public CI without proprietary dependencies.
- [ ] Verified native MCP tools/list and tools/call on supported operating systems.
- [ ] Verify GitHub private vulnerability reporting is enabled.

## Milestones

- M0 / #2: Bilingual public documentation and native MCP protocol contract tests.
- M1 / #3: Version-aware Synplify report format inventory and original synthetic fixtures.
- M2 / #4: Bounded .srr parser, diagnostics and explicit parse-health statuses.
- M2 / #5: Resource utilization and preliminary timing with source lines, units and constraints.

- M4 / #7: Deterministic comparisons across runs, including incompatible contexts and unknown fields.

## Open acceptance questions

Measure OS/product version coverage, license behavior, runtime and output sizes, malformed report behavior, cancellation, and independently validated timing. Commercial Synplify integration requires a separate licensed acceptance environment. No untested Synplify release is claimed as supported.
