# Code of conduct

[Русский](CODE_OF_CONDUCT.md)

We welcome people of different experience levels, locations and organizations. Keep technical discussions respectful, specific and evidence-based.

Harassment, threats, discriminatory behavior, disclosure of private information without consent and pressure on other contributors are unacceptable. Constructive criticism of technical decisions is welcome when supported by reproducible examples.

Report conduct violations privately to project maintainers through an available private GitHub channel. Use GitHub security advisories for security disclosures if configured. Never expose victims' identities or confidential material in public issues.

Maintainers may moderate content, close discussions or limit participation. Decisions should be proportionate and fairly applied.
