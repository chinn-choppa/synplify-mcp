# История изменений

Все существенные изменения будут отражаться здесь. Формат основан на Keep a Changelog; версии планируются по SemVer после стабилизации публичного интерфейса.

## [Unreleased]

### Кандидат 0.1.0a1 (не опубликован)
- Шесть публичных инструментов MCP, безопасность Windows .exe и операторского манифеста.
- Универсальный `uv.lock`, воспроизводимый CI и проверка установки wheel/sdist через настоящий MCP stdio.
- Публикация GitHub prerelease только по явно созданному тегу; вендорский Synplify `NOT_RUN`.

### Добавлено
- Независимый Python-пакет и точка входа stdio MCP.
- Инструменты `server_info`, `tool_status`, `parse_diagnostics` для первичного прототипа.
- Политика безопасности, контракт результатов, CI, дорожная карта и руководство для участников.
- Экспериментальный `parse_srr`: проверка workspace, источники диагностик, контроль кодировки и ограничение ответа (задача #4).
- Консервативная нормализация подписанных ресурсов и предварительного timing с исходными строками, состояниями отсутствия/неоднозначности и контекстом устройства (задача #5).

- Опциональная операция `run_approved_synthesis`: разрешённые оператором проекты `.prj`, фиксированный `-batch`, тайм-ауты, защита путей и ограниченный локальный stdout (задача #6).

### Ограничения
- Коммерческий Synplify, лицензии и настоящие FPGA-проекты не проверялись. MCP-протокол в CI проверен в памяти и через реальный subprocess stdio.

- Интегрировано сравнение отчётов с проверкой совместимости контекста (#7).
